Hero background · two builds

One loop, two position functions

Both references run the same machine: a field of cards larger than the viewport, moved by a damped pointer value, with each card assigned a depth. What separates them is only where the cards are placed. Everything here is CSS 3D transforms and one requestAnimationFrame loop — no WebGL, no libraries.

Track

Pointer position becomes an offset from centre, normalised to roughly −0.5 → 0.5 on each axis.

Damp

Each frame eases toward that target instead of snapping to it. This is the whole reason the motion feels expensive — drag the Ease slider to 20 and it turns cheap immediately.

Distribute

Multiply the eased offset by each card's depth. Different speeds read as different distances, and the parallax does the rest.

// scatter — depth scales a flat translation
card.style.transform =
  `translate3d(${bx - x * 260 * d}px, ${by - y * 170 * d}px, 0)
   rotate(${rot}deg) rotateY(${-x * 13 * d}deg) rotateX(${y * 9 * d}deg)`;

// cylinder — depth falls out of the geometry
const theta = i / N * Math.PI * 2 + rotation;   // rotation follows the pointer
const depth = Math.cos(theta);                   // +1 front, −1 back

card.style.transform =
  `rotateX(${tilt}deg) rotateY(${theta}rad) translateZ(${R}px)
   rotateY(${-theta * 0.82}rad) translateY(${yOff}px)`;

face.style.opacity = 0.22 + 0.78 * (depth + 1) / 2;
face.style.filter  = `blur(${quantise((1 - (depth + 1) / 2) * 5)}px)`;

The cylinder needs transform-style: preserve-3d on the stage, which buys you something important for free: the headline sits inside that same 3D space at z = 0, so the browser sorts cards in front of and behind it by real geometry. No z-index bookkeeping. In scatter mode the stage is flat, so front and back cards are split with z-index around the headline's layer instead.

Blur is quantised to whole pixels and lives on an inner element, never on the transformed card — animating a filter per-frame on a 3D-positioned node is what turns a smooth hero into a slideshow. Reduced-motion visitors get the same composition, held still.
