Flat cards, moved through real depth

Every card stays face-on — no rotateX, no rotateY, so nothing ever skews into a trapezoid. The only 3D is where a card sits: each one carries a translateZ, and the stage's perspective turns that depth into size and speed on its own. Cards stay 2D objects; the space they move through is 3D.

Reach

Each card measures its own distance to the cursor and gets an influence value that smoothly falls off to zero at the edge of the radius. Nothing outside the radius moves at all.

Pull

Inside that radius the card slides along the vector toward the cursor — move up, they rise toward you. It also gains translateZ, so it lifts off the plane and grows as it comes forward.

Settle

Influence is computed from each card's resting position, never its pulled one. That keeps the force a pure function of where the cursor is, so cards can't chase themselves into a feedback wobble.

// how close is the cursor, 1 at the centre → 0 at the edge of reach
const dx = cursorX - restX, dy = cursorY - restY;
let f = Math.max(0, 1 - Math.hypot(dx, dy) / reach);
f = f * f * (3 - 2 * f);                    // smoothstep, no hard rim

// slide toward the cursor and lift toward the camera
const pullX = dx * f * 0.3 * strength;
const pullY = dy * f * 0.3 * strength;
const lift  = f * 110 * strength;

card.style.transform =
  `translate3d(${restX + pullX}px, ${restY + pullY}px, ${baseZ + lift}px)
   rotate(${tiltInPlane}deg)`;     // rotate() is 2D — the card stays flat

The cylinder mode runs the identical force. Its cards are placed with rotateY(θ) translateZ(R) and then fully counter-rotated by rotateY(−θ), which cancels the turn and leaves every card square to the camera while still orbiting through depth. Because that counter-rotation lands the card back in camera-aligned space, the same pull vector can simply be appended to the transform — divided by the card's perspective factor, so a pull of 40px reads as 40px on screen whether the card is near or far.

One requestAnimationFrame loop, twelve nodes, no libraries. Blur is quantised to whole pixels on an inner element so the transformed node stays a clean 3D participant, and reduced-motion visitors get the same composition held still.
